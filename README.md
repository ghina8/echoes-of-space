## 🚀 About the Project

Echoes of Space is an interactive educational web experience that brings abandoned space equipment on the Moon and Mars back to life through immersive first-person storytelling.

Developed for the NASA Space Apps Challenge, “Abandoned but not Forgotten: Storytelling about NASA's Discarded Equipment on the Moon and Mars,” the platform combines official NASA mission information with creative storytelling, interactive exploration, and gamified learning.

Our goal is to inspire young space explorers aged 10–18 and make space science more accessible, memorable, and engaging.

## ✨ Features

- Interactive exploration of the Moon and Mars.
- Four historic space equipment profiles.
- First-person storytelling with four chapters per mission.
- NASA mission imagery and scientific information.
- Interactive glossary for scientific terminology.
- Educational facts and critical-thinking questions.
- Four mission-specific quizzes with 12 questions in total.
- Immediate quiz feedback and educational explanations.
- Cinematic animations and interactive navigation.
- Public access without registration or login.

## 💻 Getting Started

Clone the repository:

`git clone https://github.com/ghina8/echoes-of-space.git`

Navigate to the project directory:

`cd echoes-of-space`

Install dependencies:

`npm install`

Start the development server:

`npm run dev`

Create a production build:

`npm run build`
